# Learn Playwright with AI Self-Healing Locator Flow

This project is a beginner-friendly Playwright setup that demonstrates:
- a Page Object Model structure
- AI-assisted self-healing locator retry
- failure artifact generation
- Jenkins CI/CD integration
- HTML and JSON reporting

## Project Structure

- `tests/` - Playwright test cases
- `pages/` - Page Object Model classes
- `locators/` - Selector definitions in JSON
- `utils/` - Helper utilities such as self-healing click logic
- `ai/` - Python helper for AI-style locator suggestions
- `scripts/` - Helper scripts for CI summary generation
- `reports/` - Failure JSON, screenshots, and generated summaries
- `playwright-report/` - HTML report generated by Playwright
- `jsonReports/` - JSON report output
- `Jenkinsfile` - Jenkins pipeline definition

## Prerequisites

Install Node.js and Python.

Then install project dependencies:

```bash
npm install
npx playwright install --with-deps
```

## Run Locally

Run the test suite:

```bash
npx playwright test
```

Run a specific test file:

```bash
npx playwright test tests/login.test.ts
```

## AI Self-Healing Flow

The flow works like this:
1. Playwright tries to click a locator.
2. If the locator fails, the failure details are captured.
3. A Python helper receives the failure payload.
4. The helper suggests a better selector.
5. Playwright retries the click with the suggested locator.

This is implemented in:
- `pages/loginPage.ts`
- `utils/aiClick.ts`
- `ai/locator_helper.py`

## Failure Artifacts

When a test fails, the project saves:
- screenshots
- HTML snapshots
- error text files
- JSON payloads for AI analysis

These are stored under the `reports/` folder.

## Reports

Playwright generates:
- HTML report in `playwright-report/`
- JSON report in `jsonReports/`

## Jenkins CI/CD

A Jenkins pipeline is included in `Jenkinsfile`.

It performs:
1. dependency installation
2. Playwright browser installation
3. test execution
4. AI summary generation
5. artifact archiving and HTML report publishing

## Generate AI Failure Summary

Run:

```bash
node scripts/generate-ai-summary.js
```

This creates:

```text
reports/ai-failure-summary.md
```

## Notes

- The current flow uses a simple AI-style helper to demonstrate the architecture.
- You can later replace the Python helper with a real LLM API or a more advanced selector recommendation model.
